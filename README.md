# 🤖 AI Todo Assistant (챗봇 투두 리스트)

지능형 대화형 AI 챗봇이 결합된 생산성 투두 리스트 애플리케이션입니다.
자연어로 대화하듯 할 일을 등록, 체크, 삭제하고 목표 달성을 위한 추천 루틴을 생성할 수 있습니다.

## ✨ 핵심 기능

### 1. 💬 지능형 AI 챗봇 (AI Assistant)
- **자연어 일정 등록**:
  - *"내일 오후 3시 팀 스프린트 회의 추가해줘"* (날짜, 시간, 카테고리, 우선순위 자동 감지)
- **자연어 완료 및 삭제**:
  - *"운동 다 했어"*, *"장보기 완료 처리해줘"*
  - *"회의 취소됐으니 삭제해줘"*
- **목표 분해 & 루틴 추천 (Plan Generation)**:
  - *"다이어트 계획 세워줘"*, *"코딩 공부 루틴 추천해줘"*, *"이사 준비 일정 짜줘"*
  - 챗봇이 3~5단계의 실천 가능한 항목을 제안하며, 카드 내의 버튼 클릭 한 번으로 일괄 등록 가능!
- **일정 브리핑 & 현황 요약**:
  - *"오늘 할 일 뭐야?"*, *"중요한 일 브리핑해줘"*
- **듀얼 엔진 지원**:
  - **내장 한국어 NLP 엔진**: 외부 API 키 없이 즉시 100% 작동.
  - **Google Gemini API 연동**: 설정에서 개인 API Key 입력 시 최신 Gemini LLM과 연동되어 고도화된 대화 지원.

### 2. 📋 풀스택 투두 리스트 관리
- **풍부한 메타데이터**: 카테고리(업무, 공부, 일상, 건강, 기타), 마감일(D-Day 표시), 시간, 우선순위(높음, 보통, 낮음)
- **실시간 통계 & 프로그레스 바**: 오늘의 달성률(%), 진행 중, 완료됨, 마감 임박 태스크 한눈에 확인
- **검색, 필터, 정렬**:
  - 텍스트 실시간 검색
  - 진행 중 / 완료됨 탭
  - 카테고리별 필터 및 마감일/우선순위/최신순 정렬
- **인라인 편집 & 영구 저장**: LocalStorage를 활용하여 브라우저를 닫아도 데이터 유지

## 🚀 빠른 시작

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속.

### 3. 프로덕션 빌드
```bash
npm run build
```

## 🛠 기술 스택
- **프론트엔드**: React 19, TypeScript
- **스타일링**: Tailwind CSS v4, Lucide React (아이콘)
- **빌드 도구**: Vite 6
- **AI / NLP**: Custom Korean Rule-based NLP Parser + Google Gemini API (옵션)
